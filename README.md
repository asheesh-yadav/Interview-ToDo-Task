# React Todo App

##  Description

Todo app built using React.
Users can add, delete, mark tasks as completed, and filter tasks based on their status.

---

##  Features

* Add new tasks
* Delete tasks
* Mark tasks as completed
* Filter tasks:

  * All
  * Completed
  * Pending
* Data saved in localStorage (persists after refresh)

---

##  Tech Stack

* React (Functional Components)
* React Hooks (useState, useEffect)
* Context API
* CSS (Basic styling)

---

##  Project Structure

src/

* context/
* TodoContext.jsx
* App.jsx
* TodoApp.jsx

---

##  How to Run

1. Clone the repository
2. Install dependencies:

   npm install
   ```
3. Start the project:

   ```bash
   npm run dev
   ```
